# سجل الفصل

برنامج ويب لتسجيل الطلاب حسب فصولهم، وإدخال الدرجات (سريع ويدوي)، وتسجيل الحضور والغياب، وتصدير الدرجات والمتوسطات إلى ملف Excel (xlsx) فيه اسم الطالب في الصف ونوع الدرجة في العمود. واجهته عربية من اليمين لليسار، ويعمل على الهاتف واللوحي والكمبيوتر، ويمكن تثبيته كتطبيق على الشاشة الرئيسية ويعمل دون اتصال بعد أول فتح.

## هيكل المشروع

```
.
├── render.yaml        إعداد النشر على Render
├── public/            كل ملفات الموقع (ثابتة، بلا خادم)
│   ├── index.html
│   ├── style.css
│   ├── app.js
│   ├── sw.js          العمل دون اتصال
│   ├── manifest.webmanifest
│   └── icon*.png / icon.svg
└── README.md
```

## إدخال الدرجات

- من ملف الطالب اختر **تاريخ الإدخال** ثم اضغط خانة الدرجة وبعدها الرقم، فتُسجَّل بهذا التاريخ.
- يمكنك تسجيل **أكثر من درجة في اليوم الواحد** (واجبان واختبار مثلاً)، وفي أيام مختلفة. بعد آخر درجة تظهر دائماً خانة **+ جديدة**، فلا يوجد حد لعدد الدرجات.
- الإدخال اليدوي يتيح كتابة الدرجة والدرجة النهائية والتاريخ وملاحظة.
- في **سجل الطالب** يظهر لكل درجة تاريخها وشهرها، ويمكن تعديل التاريخ مباشرة.

## التصدير

يُنتج البرنامج ملف `.xlsx` حقيقياً بدون أي مكتبة خارجية، بصفحة من اليمين لليسار:

- **النطاق:** كل طلاب الفصل، أو طالب واحد، أو طلاب معينون.
- **الدرجات والمتوسطات معاً (الأفضل):** ملف واحد بأربع أوراق:
  - **المتوسطات:** متوسط ونسبة وعدد درجات كل نوع (الواجب، الاختبار…) لكل طالب، ثم المجموعات والإجمالي.
  - **كل الدرجات:** كل درجة في عمود، مرتبة من الأقدم إلى الأحدث.
  - **السجل التفصيلي:** صف لكل درجة بتاريخها وشهرها ونوعها ومجموعتها، مع أسهم تصفية في العناوين.
  - **المتوسط الشهري:** متوسطات كل شهر على حدة.
- **كل الدرجات المدخلة فقط**، أو **المتوسطات فقط**.
- لكل نوع من الدرجات لون خاص، والأنواع داخل مجموعة (مثل المشاركة اليومية) تأخذ لون المجموعة.
- خيار إضافة أعمدة الحضور والغياب.

## المشاركة اليومية (12 درجة)

من **الإعدادات** اضغط **إضافة قالب المشاركة اليومية (12 درجة)** فيُضاف:

| المكوّن | الدرجة | طريقة الإدخال |
|---|---|---|
| اختبار الخميس | 6 | اختبارات من 10، وتُحوَّل بمعادلة (مجموع الطالب ÷ الممكن) × 6 |
| التفاعل داخل الصف | 4 | رموز + ✓ − من خريطة الجلوس (وضع «تسجيل التفاعل»)، وتُقرَّب إلى نصف درجة |
| الانضباط والاستعداد | 2 | درجتان (أدوات، هدوء) ويمكن إنقاص نصف درجة |

- في خريطة الجلوس اختر **تسجيل التفاعل** واضغط المقعد لتبديل الرمز (+ ← ✓ ← − ← مسح) لتاريخ الحصة المحدد.
- الرموز تُحسب هكذا: + = 1، ✓ = 0.75، − = 0، ثم متوسط الحصص × 4.
- غياب الطالب بعذر لا يُحسب صفراً، لأن المتوسط يؤخذ من الدرجات المدخلة فقط.
- المجموع من 12 يظهر في ملف الطالب وفي جدول الدرجات وفي ملف Excel.
- يمكنك تعديل الأوزان والأسماء أو إنشاء مجموعات أخرى من أنواع الدرجات في الإعدادات (الدرجة المعتمدة + المجموعة).

## الرفع على GitHub

```bash
git init
git add .
git commit -m "سجل الفصل"
git branch -M main
git remote add origin https://github.com/<اسم-المستخدم>/sijil-alfasl.git
git push -u origin main
```

أنشئ المستودع الفارغ `sijil-alfasl` على github.com أولاً، ثم نفّذ الأوامر أعلاه.

## النشر على Render

**الطريقة الأولى (تلقائية):**
1. في Render اختر **New** ثم **Blueprint**.
2. اربط حساب GitHub واختر المستودع.
3. يقرأ Render الملف `render.yaml` وينشر الموقع.

**الطريقة الثانية (يدوية):**
1. اختر **New** ثم **Static Site** واختر المستودع.
2. اترك **Build Command** فارغاً.
3. اكتب في **Publish Directory**: `public`
4. اضغط **Create Static Site**.

بعد دقيقة يعطيك Render رابطاً من الشكل `https://sijil-alfasl.onrender.com`.

## أين تُحفظ البيانات؟

تُحفظ في متصفح الجهاز نفسه (`localStorage`). هذا يعني:

- البيانات خاصة بالجهاز والمتصفح الذي أدخلتَها فيه، ولا تنتقل تلقائياً إلى جهاز آخر.
- مسح بيانات المتصفح يمسح السجل. لذلك استخدم **الإعدادات ← تنزيل نسخة احتياطية** بشكل دوري.
- لنقل البيانات إلى جهاز آخر: نزّل النسخة الاحتياطية، ثم افتح البرنامج على الجهاز الجديد واختر **استعادة من ملف**.

إذا أردت مزامنة تلقائية بين عدة أجهزة أو عدة معلمين، يلزم إضافة خادم وقاعدة بيانات إلى المشروع.

## تحديث الموقع

أي `git push` إلى الفرع `main` يعيد نشر الموقع تلقائياً على Render. عند تغيير ملفات `public/` ارفع رقم `VERSION` في `public/sw.js` ليتحدث التخزين المؤقت عند المستخدمين.
