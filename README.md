# سجل الفصل

برنامج ويب لتسجيل الطلاب حسب فصولهم، وإدخال الدرجات (سريع ويدوي) بتاريخ كل درجة، وتسجيل الحضور والغياب والمشاركة اليومية، وتصدير الدرجات والمتوسطات إلى ملف Excel. واجهته عربية من اليمين لليسار ويعمل على الهاتف واللوحي والكمبيوتر.

في هذا الإصدار تُحفظ البيانات على **خادم وقاعدة بيانات Neon**، فتسجّل الدرجات وتفتحها من أي جهاز بكلمة مرور واحدة.

## كيف يعمل

```
المتصفح (هاتف / كمبيوتر)  ⇄  خادم Node على Render  ⇄  قاعدة Neon (Postgres)
```

- **تسجيل الدخول:** كلمة مرور واحدة (متغير `APP_PASSWORD`). بعد الدخول يبقى الجهاز مسجّلاً 90 يوماً.
- **الحفظ:** كل تغيير يُرسل إلى الخادم تلقائياً بعد لحظة. الحالة تظهر أعلى الصفحة (تمت المزامنة / جارٍ الحفظ / غير متصل).
- **دون إنترنت:** يستمر البرنامج بالعمل ويحفظ على الجهاز، وعند عودة الاتصال تُرسل التغييرات تلقائياً.
- **جهاز ثانٍ:** عند فتح البرنامج أو العودة إليه تُحمَّل آخر بيانات من الخادم، وزر «مزامنة الآن» في الإعدادات يفرض ذلك.
- **أول دخول من جهاز فيه بيانات محلية:** تُدمج فصوله مع ما على الخادم ولا يُحذف شيء.
- **الخروج:** من الإعدادات، ويمسح النسخة المحلية من الجهاز (تبقى البيانات على الخادم).

## الإعداد خطوة بخطوة

### 1) أنشئ قاعدة البيانات على Neon

1. ادخل neon.tech وسجّل حساباً مجانياً، ثم **Create project** (اختر أقرب منطقة).
2. من لوحة المشروع اضغط **Connect**.
3. فعّل خيار **Connection pooling**، وانسخ سلسلة الاتصال. شكلها:
   `postgresql://المستخدم:كلمة-السر@ep-xxxx-pooler.region.aws.neon.tech/neondb?sslmode=require`
4. لا تحتاج إنشاء جداول، فالخادم ينشئ جدول `docs` تلقائياً عند أول تشغيل.

### 2) ارفع المشروع على GitHub

استبدل محتويات مستودعك القديم بملفات هذا المجلد (كلها، ومنها `server.js` و`package.json` و`render.yaml`)، ثم:

```bash
git add .
git commit -m "خادم Neon"
git push
```

أو من موقع GitHub: **Add file ← Upload files** واسحب محتويات المجلد (وليس المجلد نفسه).

### 3) انشره على Render كخدمة ويب

الموقع القديم كان من نوع Static Site ولا يمكن تحويله، لذلك أنشئ خدمة جديدة:

1. في Render اختر **New ← Web Service** واربط المستودع.
2. اكتب الإعدادات:
   - **Runtime:** Node
   - **Build Command:** `npm install --omit=dev`
   - **Start Command:** `node server.js`
   - **Health Check Path:** `/api/health`
3. من **Environment** أضف:

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | سلسلة اتصال Neon من الخطوة 1 |
| `APP_PASSWORD` | كلمة مرور قوية تفتح بها البرنامج |
| `SESSION_SECRET` | أي نص عشوائي طويل (اختياري لكنه مفضّل) |

4. اضغط **Create Web Service**. بعد دقائق يظهر الرابط `https://....onrender.com`.

يمكنك بدلاً من ذلك اختيار **New ← Blueprint**، فيقرأ Render الملف `render.yaml` ويطلب منك `DATABASE_URL` و`APP_PASSWORD`.

يمكنك حذف الـ Static Site القديم بعد التأكد من عمل الخدمة الجديدة.

### 4) أول استخدام

افتح الرابط، أدخل كلمة المرور. إن كانت عندك بيانات في هذا المتصفح من النسخة السابقة فستُرفع إلى الخادم تلقائياً. افتح الرابط نفسه على هاتفك وأدخل الكلمة، فتظهر الفصول نفسها.

## ملاحظات مهمة

- **الخطة المجانية في Render** تُوقف الخدمة بعد نحو 15 دقيقة دون استخدام، وأول فتح بعد ذلك قد يستغرق دقيقة. بعدها تعمل بسرعة. الاشتراك المدفوع يلغي هذا التأخير.
- **قاعدة Neon المجانية** قد تنام أيضاً عند عدم الاستخدام وتستيقظ خلال لحظات، والخادم يعيد المحاولة تلقائياً.
- **النسخ الاحتياطي:** من **الإعدادات ← تنزيل نسخة احتياطية** ملف JSON يمكن استعادته. خذ نسخة بين فترة وأخرى رغم وجود الخادم.
- **تغيير كلمة المرور:** غيّر `APP_PASSWORD` في Render، فتنتهي صلاحية دخول كل الأجهزة وتُطلب الكلمة الجديدة.
- **كلمة المرور:** ست محاولات خاطئة من العنوان نفسه تُقفل الدخول 15 دقيقة.
- **التعديل من جهازين في وقت واحد:** يُحفظ آخر تعديل لكل فصل. لا تعدّل الفصل نفسه من جهازين في اللحظة ذاتها.
- هذا الإصدار لمعلم واحد. لعدة معلمين لكل منهم حسابه يلزم تطوير إضافي.

## تشغيله على جهازك للتجربة

```bash
APP_PASSWORD=1234 node server.js
```

ثم افتح `http://localhost:3000`. بدون `DATABASE_URL` تُحفظ البيانات في ملف `data/store.json` (للتجربة فقط). لتجربة Neon محلياً: `npm install` ثم أضف `DATABASE_URL`.

## التصدير إلى Excel

ملف `.xlsx` حقيقي من اليمين لليسار:

- **النطاق:** كل طلاب الفصل، أو طالب واحد، أو طلاب معينون.
- **الدرجات والمتوسطات معاً:** أربع أوراق: المتوسطات، كل الدرجات، السجل التفصيلي بالتاريخ والشهر (مع تصفية)، والمتوسط الشهري.
- لكل نوع درجة لون خاص، والأنواع داخل مجموعة (مثل المشاركة اليومية) تأخذ لون المجموعة.

## المشاركة اليومية (12 درجة)

من **الإعدادات** اضغط **إضافة قالب المشاركة اليومية (12 درجة)**: اختبار الخميس (6) + التفاعل داخل الصف بالرموز + ✓ − (4) + الانضباط والاستعداد (2). المعادلة: (مجموع درجات الطالب ÷ الممكن) × الوزن.

## السلوك (خصم بالأحمر)

في خريطة الجلوس اختر تبويب **تسجيل السلوك** ثم اضغط مقعد الطالب: اختر **− نصف درجة** أو **− درجة** مع سبب اختياري (يمكن أكثر من خصم في اليوم، وزر «تراجع» يلغي آخر خصم). يظهر الخصم بالأحمر على المقعد وفي ملف الطالب، ويُطرح من مجموع مجموعته (المشاركة اليومية) ومن الإجمالي. في Excel يظهر عمود «السلوك (خصم)» بلون أحمر وأرقام سالبة حمراء، ويُسجَّل كل خصم بتاريخه وسببه في «السجل التفصيلي».

## تصدير فترة محددة

في تبويب **التصدير** (وفي تصدير الطالب الواحد) قسم **الفترة**: كل الفترة، أو **شهر أو عدة شهور**، أو **أسبوع أو عدة أسابيع** (الأسبوع من السبت إلى الجمعة). تُطبَّق الفترة على الدرجات والمتوسطات والحضور وعنوان الملف واسمه. ورقة «السجل التفصيلي» فيها لكل درجة: اليوم والتاريخ والشهر والأسبوع.

## تبويبات خريطة الجلوس وإدارة الطلاب

- من **الإعدادات ← تبويبات خريطة الجلوس** تختار ما يظهر في الشريط العلوي للخريطة: الحضور والتفاعل والسلوك وتعديل الطلاب، وأي نوع درجة (اختبار، واجب…). عند تفعيل نوع درجة يظهر تبويب باسمه، فتضغط مقعد الطالب وتختار الدرجة بتاريخ اليوم المحدد (يمكن أكثر من درجة في اليوم، وزر «تراجع» يلغيها).
- **إضافة طالب:** زر «+ طالب» في أعلى الخريطة، أو الضغط على مقعد فارغ.
- **حذف أو تعديل طالب:** تبويب «تعديل الطلاب» ثم الضغط على المقعد، أو من تبويب «الطلاب». الحذف يمس هذا الطالب فقط ولا يمس بقية الفصل.
